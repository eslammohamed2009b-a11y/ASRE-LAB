# ASRE-Lab v1.0.0

First v1 release of ASRE-Lab, an engineering research platform for controlled design comparison, bounded physical simulation, traceable evidence, analysis, human-reviewed decisions, and persisted reports.

## Release status

- Final live release acceptance: **PASS**
- Release blockers: **None**
- Known P0: 0
- Known P1: 0
- Known material P2: 0

## v1 workflow

Study → Design → Physics → Validation → Run → Evidence → Human Decision → Report

The release keeps scientific claims bounded to persisted evidence. Missing benchmark or refinement evidence remains missing, Scientific Trust is an evidence-state classification rather than an AI confidence score, and final engineering decisions require human action.

## Ongoing validation

This release note records the original v1 acceptance. The repository may evolve afterward; current validation state and known gaps are maintained in the validation and release documentation.
