# ASRE-Lab v1.0.0

First frozen v1 release of ASRE-Lab, an engineering research platform for controlled design comparison, bounded physical simulation, traceable evidence, analysis, human-reviewed decisions, and persisted reports.

## v1 workflow

Study → Design → Physics → Validation → Run → Evidence → Human Decision → Report

The release keeps scientific claims bounded to persisted evidence. Missing benchmark or refinement evidence remains missing, Scientific Trust is an evidence-state classification rather than an AI confidence score, and final engineering decisions require human action.

## Freeze

The v1 application code is frozen at the accepted baseline. Normal feature development moves to the next version.
